# MicroGrid - Born to Connect

## Introduction

MicroGrid is a modular robotic swarm developed for the World Robot Olympiad (WRO) 2026.
The project focuses on decentralized autonomous micro robots capable of wireless communication, cooperative movement, and dynamic physical self-assembly into larger adaptive structures.

## Project Areas

- Swarm robotics
- Embedded systems
- Wireless communication
- Autonomous coordination
- Modular robotic structures
- Simulations
- 3D planning

## Repository Structure

- /docs          - Documentation and design reviews
- /firmware      - Embedded software and robot control
- /simulation    - Webots simulation environments
- /hardware      - PCB and CAD files
- /assets        - Images, diagrams, branding


## Current Status

Early architecture and simulation phase.

### Versions

**Mark 1 (Mk. 1)** is the primary robot version.
**Revisions (Rev. A, Rev. B, etc.)** are assigned to hardware and mechanical design changes.
**Software versions (v. 1, v. 2, etc.)** are assigned to programs and controllers.

### Simulation

The Mk. 1 Rev. A robot is considered suitable as the baseline platform for future development.
Controller v. 1 provides manual control functionality.
Steering remains challenging, and precise positioning is currently difficult to achieve.
