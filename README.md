# MicroGrid - Born to Connect

## Introduction

MicroGrid is a modular robotic swarm developed for the World Robot Olympiad (WRO) 2026.
The project focuses on decentralized autonomous micro robots capable of wireless communication, cooperative movement, and dynamic physical self-assembly into larger adaptive structures.

## Project Areas

- Swarm robotics
- Embedded systems
- Wireless communication
- Autonomous coordination
- Modular robotic structures
- Simulations
- 3D planning

## Repository Structure

- /docs          - Documentation and design reviews
- /firmware      - Embedded software and robot control
- /simulation    - Webots simulation environments
- /hardware      - PCB and CAD files
- /assets        - Images, diagrams, branding
